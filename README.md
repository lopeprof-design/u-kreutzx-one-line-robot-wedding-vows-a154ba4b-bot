One-Line Robot Wedding Vows: one line, 114 characters, of wedding vows for a robot couple — it vows to love in sickness and in health, in low battery and in airplane mode, until death do us factory reset. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), one line of 1–160 characters, mode 0644, and reads it back to confirm the bytes are verbatim.
